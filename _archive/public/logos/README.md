# Firma Logoları

Bu klasöre çalıştığınız firmaların logolarını ekleyin.

## Logo Gereksinimleri:
- Format: PNG veya SVG (şeffaf arka plan önerilir)
- Boyut: Yaklaşık 200x80px (otomatik olarak ölçeklendirilecek)
- Dosya adı: kucuk-harfler-ve-tire.png

## Örnek dosya adları:

- fedex-logo.png
- ups-logo.png
